    Instalar Spec Kit Orchestrator

    Instala solamente nuestros Agents, Commands y Skills en la configuración global de OpenCode. Spec Kit debe instalarse por separado en cada proyecto.

    Abrir repositorio ↗
    Requisitos previos
    • Ubuntu/Linux, Git y OpenCode instalados.
    • Spec Kit y su integración pública de Skills instalados independientemente en el proyecto.
    • Bash y utilidades estándar; Python 3 solo para regenerar el dashboard.
    Alcance seguro

    El instalador escribe solo Agents, Commands y Skills del paquete. No modifica Spec Kit, archivos de configuración de OpenCode ni plugins. Colisiones diferentes detienen la operación.

    Clonar e instalar

    Desde un terminal Linux

    git clone https://github.com/agncyofleads/spec-kit-orchestrator.git cd spec-kit-orchestrator ./install.sh

    Actualizar

    Ejecuta desde el directorio clonado

    git pull --ff-only ./update.sh

    La actualización se detiene ante archivos modificados localmente o colisiones; resuelve el conflicto y vuelve a intentarlo.

    Desinstalar

    Los cambios locales requieren confirmación

    ./uninstall.sh

    Los archivos modificados se conservan por defecto si no hay terminal interactiva. Los archivos ajenos y Spec Kit permanecen intactos.

    Comandos disponibles

    Prompt templates: se invocan manualmente en OpenCode

    /sdd-init

    Inicia un proyecto nuevo —solicita sus principios antes de crear Constitution— o distingue un proyecto existente y respeta su Constitution. Luego solicita la funcionalidad para Full.

    /sdd-feature

    Inicia una funcionalidad por la ruta Full sin reinicializar el proyecto ni cambiar su Constitution.

    /sdd-delta

    Procesa un cambio acotado a una funcionalidad existente, conserva artefactos válidos y recupera fases upstream cuando haga falta.

    /sdd-resume

    Continúa únicamente desde estado, aprobaciones, artefactos y evidencia verificables; no inventa estado persistente.

    /sdd-status

    Informe consultivo, de solo lectura, limitado a rutas, evidencia y contexto proporcionados por el usuario.

    /sdd-approve

    Opcional: valida una decisión humana explícita contra un gate pendiente y su alcance. Invocarlo no constituye por sí solo una aprobación.

    Copiar solo prepara texto. Este dashboard no ejecuta shell, OpenCode ni comandos SDD. La presencia de archivos no demuestra activación runtime.
